# Architecture Decisions Index

- **ADR-0001** — SQLite is the local control-plane system of record.
- **ADR-0002** — Advisory intelligence never overrides hard safety or verification gates.
- **ADR-0003** — Parallel execution uses isolated worktrees and serialized integration.
- **ADR-0004** — Provider credentials are environment/secret-manager inputs, never project evidence.
- **ADR-0005** — Recovery is bounded and uncertainty escalates instead of becoming success.
- **ADR-0006** — Production-impacting operations require explicit human approval policy.
- **ADR-0007** — V7.0 is a completion/hardening boundary, not an invitation to add endless intelligence subsystems.
